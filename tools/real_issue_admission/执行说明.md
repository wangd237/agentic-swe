# 本地 Codex 执行说明

本包为 Evaluator 专用，禁止放入 Agent 可访问的工作目录。当前包含 20 个候选的完整 GitHub 修复 SHA、经 Commit API 核实的修复提交直接父 SHA、上游测试路径及风险记录。7 个任务的原 PR Base SHA 与实际修复前父提交不同，已修正候选基线。

1. 在独立的 Evaluator 目录运行 `python admission.py --private E:/RealIssueEvaluator`，拉取指定修复提交、导出修复前完整快照、拆分参考源码/测试/文档补丁。先试跑单任务可添加 `--task real_anyio_1466`。若先试跑，之后应使用新目录或显式选择剩余任务，脚本不覆盖已存在目录。
2. 逐项审核生成的 `review.json`：补全 Issue 原始复现和脱敏描述、独立可见测试、隐藏测试范围、Python 和依赖锁文件路径（绝对路径）、F2P/P2P/隐藏测试参数。多目的 PR 需要裁剪；原有 4 任务也需重新验证。参考 `environment_hints.md`。
3. 执行 `python validate.py E:/RealIssueEvaluator/real_anyio_1466` 等，核查测试矩阵和日志；失败任务修正环境或淘汰替换。不能将环境失败当缺陷复现。独立测试必须真正覆盖原问题，避免重复或过度泄露。
4. 在全部 20 个任务通过实际测试、重复稳定性、隔离及外部评分审查后，生成每个任务的 `audit.json`。具体字段参考 `register.py`。执行 `python register.py --private E:/RealIssueEvaluator --project E:/GH_Repositories4Learn/agentic-swe` 注册新任务及 Manifest；拒绝覆盖旧任务与旧 Manifest。

**当前关键阻塞**：20 项离线行为矩阵和参考补丁独立评分已完成，但现有批量 Agent 入口仍未接入锁定容器和独立 Evaluator 的最终判定。三个原试点已完成预设 Patch 的无 LLM 容器烟测，不能据此置位正式运行时隔离审计。pytest #15370 与 marshmallow #2869 的来源真实性还需作冻结前审查。具体记录见 [validation_progress.md](validation_progress.md)。

详细脚本约束和风险见 README.md。当前仍未冻结，不将通过离线行为测试等同于完整准入。
